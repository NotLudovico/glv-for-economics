# Thesis figure provenance

Thesis figures live in `thesis/*.png` but are generated by scripts in **two repos** and
were copied in (and renamed) by hand. This table records which script makes each, so any
figure can be traced and regenerated.

**The authoritative relative-GLV model is the sibling repo `../relative-glv`**
(`relative_glv/model.py`):
- `kind="powerlaw"` = mean-degree normalization, `α_ij = μ/C + (σ/√C) z_ij`
- `kind="powerlaw_owndeg"` = own-degree, `α_ij = μ/k_i + (σ/√k_i) z_ij`

See `eq:normalizations` in `chapters/model.tex`.
